# Changelog

## 1.5.0 — 2026-11-18
- **Red crits**: crit chance past 100% rolls higher-magnitude crits. Each full 100% over is a
  guaranteed tier, the remainder is the chance of the next (max tier 4). Each tier multiplies
  crit damage by 1.5× (raised by red crit nodes). Red / purple damage numbers.
- **13 new cluster patterns**, 6–25 nodes, with loops, 2–7 notables or capstones and at least two
  exits at right angles.
- **Orbit exits** grow the next cluster around the tree instead of away from it.
- **Stat desire**: new clusters' stats follow the frontier node, its neighbours and your
  investment, with noise; every cluster has a "New direction" exit.
- Mechanized / Mutated levels now equal Evolution (positive / negative; dual evolution uses
  both). Flavoured clusters start at 0% and gain 2.5% per level (max 35%).
- Wider stat pools for Mechanized and Mutated clusters.
- Minor side nodes: +1 Evolution, −1 Evolution or +1 Curse.
- Named notables (Crimson Focus, Bloodletter, Lucky Break, Scrap Magnet, Second Wind,
  Sharpened Mind, Adaptive Plating, Mutagenic Gland, Hexed Charm), Crimson Edge and Sniper's
  Patience oddities, Blood Moon relic.

## 1.4.0 — 2026-11-15
- Frontier reveals place tidy geometric patterns (7–14 nodes) instead of loose strands, with
  minimum spacing and no crossing lines; patterns can curl back and link to the tree.
- Fix: the tree reset after quitting and continuing a saved run (the game hashes nested
  strings on load; the mod now reverses that).
- Fix: co-op players couldn't select the Skill Tree button with a controller.

## 1.3.1 — 2026-11-14
- First Workshop release.
- Skill Tree shop button matches the shop's own buttons.

## 1.3.0 — 2026-11-14
- Oddity capstones (secondary stats) and rare relics (Bottomless Bank, Evergreen, Extra
  Arsenal, Font of Insight, Treasure Map, Lumberjack, Shopkeeper's Favor, Aegis).
- Fix: the shop button couldn't be selected with a controller in solo.

## 1.2.0 — 2026-11-14
- Mechanized, Mutated and Cursed frontier nodes that scale with your level on each path.
- Every reveal bridges into the existing tree.

## 1.1.1 — 2026-11-14
- Fix: script error that stopped the tree from opening after waves.

## 1.1.0 — 2026-11-14
- Endless frontier: keystones and path ends grow procedurally generated branches, with random
  capstones carrying bonus effects.

## 1.0.0 — 2026-11-14
- Path of Exile style passive tree: level-ups give skill points for a 105-node tree in 8
  sectors. Opens after waves with new points and from the shop (P / Back). Co-op support,
  Mod Options settings, refunds.
